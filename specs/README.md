# Specification Pack
This directory is the normative SDD layer for Cursor work on **SME Credit Underwriting Intelligence Workbench**.

Requirement families:
- `CRD-BR-*` business requirements
- `CRD-FR-*` functional requirements
- `CRD-NFR-*` non-functional requirements
- `CRD-SEC-*` security/safety/governance requirements
- `CRD-DATA-*` data contracts (`DOMAIN_MODEL.md` is the canonical type system)
- `CRD-TOOL-*` agent/tool contracts
- `CRD-AC-*` acceptance criteria

Original case documents and evidence remain authoritative inputs; this pack makes their engineering implications explicit and traceable.
