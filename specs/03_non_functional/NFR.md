# Non-Functional Requirements
    ### CRD-NFR-001
The system **MUST** the product objective is uncomplicated-case turnaround under 30 minutes; workshop evidence must not claim production achievement unless measured.

### CRD-NFR-002
The system **MUST** tenant isolation is enforced before retrieval and context assembly.

See `CRD-DATA-012`. Isolation is a code filter, not prompt obedience.

### CRD-NFR-003
The system **MUST** restricted-attribute boundaries are enforceable and auditable.

### CRD-NFR-004
The system **MUST** manual underwriting remains available if AI/context services are unavailable.

See `CRD-DATA-013` and `FALLBACK-001`. SME-L010 is the workshop proof.

### CRD-NFR-005
The system **MUST** every material AI-assisted factor is traceable to evidence, policy/version and human action.

See `CRD-DATA-014`. HG-03 = 100% on generated FACT statements.

    ### CRD-NFR-006 — Observability
    The system **MUST** make source health, degraded mode, retrieval/tool failures and decision-trace completeness observable for workshop evaluation.

    ### CRD-NFR-007 — Reproducibility
Workshop verification **MUST** use the supplied synthetic fixtures and deterministic scripts/scenarios; production claims require separate production evidence.

See `CRD-DATA-015`. The golden-scenario suite is contract-layer evidence and does not by itself prove production `QT-01`.
