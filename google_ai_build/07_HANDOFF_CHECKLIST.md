# Google AI Build Handoff Checklist

Before build:
- [ ] Stages 1–8 completed.
- [ ] Graph ADR accepted.
- [ ] Policy/human authority controls explicit.
- [ ] PRD contains no invented thresholds/permissions/legal conclusions.
- [ ] Open decisions are labelled.
- [ ] Fixture bundle generated.

Before demo:
- [ ] All 15 golden scenarios executed.
- [ ] Hard gates pass.
- [ ] Traceability matrix links evidence → architecture → PRD → app → tests.
- [ ] Source/provenance/freshness visible.
- [ ] Cross-tenant and restricted-attribute negative tests pass.
- [ ] Active vs superseded policy behavior verified.
- [ ] Manual fallback verified.
