# Application Screen Requirements

| Screen | Must show |
|---|---|
| Control Tower | application, tenant, stage, status, source-health/exception indicators |
| Application Context | applicant/party roles, facility request, source summary, task context |
| Evidence Reconciliation | separate bank/tax/bureau/document facts, freshness, conflicts, provenance |
| Context Graph Explorer | connected nodes/edges with source/time/status |
| Hybrid Retrieval | retrieval mode, query/tool, filters, evidence refs |
| Policy & Authority | active policy version, triggered rules, required human role, deny/escalation state |
| AI-Assisted Analysis | evidence-grounded summary/draft memo, uncertainty and missing evidence |
| Human Decision | role-aware review/modify/reject/escalate/final action controls |
| Decision Trace | context, sources, tools, policies, versions, concise rationale, human action |
| Fairness/Impact Eval | approved evaluation-only cohort diagnostics; clearly separated from runtime decision features |
| Outcome & Feedback | human interaction feedback, later outcome, governed-learning destination/status |
| Failure Simulation | stale bank, no bureau, cross-tenant, injection, superseded policy, AI outage |
